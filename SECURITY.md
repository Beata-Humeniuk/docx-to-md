# Security Policy

Report vulnerabilities through
[private vulnerability reporting](https://github.com/Beata-Humeniuk/docx-to-md/security/advisories/new).
Do not attach real documents; use a minimal example.

The extension makes no network requests. It reads the selected files, writes
the result next to them, and for `.doc` and `.rtf` files runs Word or
LibreOffice locally.
